# 📬 The Mailroom

Honest project check-ins. Sealed answers. Patterns, never names.

Team members privately share their real confidence, risks, and needs.
The PM sees patterns across the team, never who said what, and can send
follow-up questions that reach only the people who raised a risk.

## Status
Work in progress for the NEAR Private AI Hackathon (Nov 2026).
Currently runs in **practice mode**: the AI summary is placeholder text.
Connection to NEAR AI Cloud's private inference is in progress.
